# QuietBroadcast

Two records a day, one at midnight and one at noon, Chicago time. The same record for everyone, chosen by the clock.

No player and no algorithm. Each slot shows one release — the
artist, the tracklist, and how long it runs.

**The log** is the second page: everything that has been on air, what it adds up
to by tag and by length, and a network of the artists that have played, joined
where they share a scene.

Electronic-adjacent music only, drawn from a personal Last.fm library and filtered
to leave out anything most people have already heard.

Static HTML. No build step, no dependencies, and as usual no tracking bs.
